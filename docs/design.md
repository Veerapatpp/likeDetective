# เงาในหมอกควัน — สรุปการออกแบบ (demo)

## แนวเกมและโลก

- roguelike สืบสวน คดีสุ่มใหม่ทุกรอบ ไม่มีการต่อสู้ เน้นการอนุมานและข้อมูล
- ยุคเครื่องจักรไอน้ำ ไฟสลัว เมืองหมอกควัน (เมืองเบรนมัวร์) โทนสยองขวัญแบบ Cthulhu
- ช่วงแรกใช้สิ่งลี้ลับที่คนทั่วโลกรู้จัก ตำนานไทยเก็บไว้เป็นภาคเสริม
- ชื่อคน สถานที่ ข้อความ และสิ่งลี้ลับแบบ outer ("ผู้มาจากห้วงลึก") สร้างขึ้นเองทั้งหมด

## โครงการเล่น (ทำแล้วใน demo)

| เฟส           | สิ่งที่ทำ                                           | งบเวลา   |
| ------------- | --------------------------------------------------- | -------- |
| 1 ที่เกิดเหตุ | คลิก hotspot ในห้อง (Phaser)                        | 120 นาที |
| 2 เก็บเบาะแส  | เลือกสถานที่บนแผนที่ + ค้นตำราที่หอสมุด             | 150 นาที |
| 3 สืบพยาน     | คุยพยาน, สังเกต/ถามข้อแก้ตัว/ตรวจสอบผู้ต้องสงสัย    | 150 นาที |
| 4 หาคนร้าย    | กระดานหลักฐาน: เลือกประเภทสิ่งลี้ลับ + ผู้ต้องสงสัย | —        |

- ล็อกลำดับเฟส แต่เลือกเองว่าจะใช้เวลาตรงไหน นาฬิกาเดินตามการกระทำ
- สติ (Sanity) ลดเมื่อเห็นสิ่งผิดธรรมชาติ ถ้าหมดจะถูกบังคับไปชี้ตัวทันที
- จบเฟส 1–3 เลือก perk 1 ใน 3 (เครื่องมือ / เทคนิคสอบปากคำ / ทักษะ) สายอาชีพกำหนดน้ำหนักของตัวเลือก

## เมนู action ในสถานที่ (เฟส 2, แบบ Walk of Life) — demo: สุสานเนินเถ้า

- คลิกสถานที่บนแผนที่ = เดินทางเข้าไป เสียเวลาเดินทางครั้งเดียว (15 นาที) แล้วเปิดเมนูให้เลือก action
- action มี 3 แบบ (`LocationActionEffect` ใน `data.ts`)
    - **search** ค้นหา: เจอเบาะแสของ trait ที่ระบุ ถ้าคดีนี้วางไว้ที่นี่ ไม่เจอถือว่าเสียเวลาเปล่า
    - **hint** สอบถามคนในพื้นที่: บอกว่า search ไหนมีของให้เจอ (ขึ้นป้าย "มีคนแนะนำ")
    - **rest** พักฟื้น: แลกเวลากับสติที่ได้คืน
- ออกไปที่แผนที่แล้วกลับเข้ามาใหม่ได้ฟรี action ที่ทำแล้วทำซ้ำไม่ได้
- สถานที่อื่นยังคลิกครั้งเดียวได้ผลทันที เพิ่มเมนูให้สถานที่อื่นได้โดยเพิ่ม entry ใน `LOCATION_ACTIONS` อย่างเดียว
  (เทสต์ `tests/locationActions.test.ts` เช็กว่าทุกเบาะแสที่วางในสถานที่นั้นได้ มี action search ที่หาเจอ)

## การการันตีว่าคดีแก้ได้ (`src/game/core/caseGen.ts`)

- เลือกคนร้ายและ **ตัวหลอก** (สิ่งลี้ลับที่มีลายเซ็นซ้ำกับคนร้ายมากที่สุด)
- วางลายเซ็น 3 ใน 4 อย่างของคนร้าย โดยชุดนี้ต้องชี้ได้แค่ชนิดเดียว และต้องมีอย่างน้อยหนึ่งอย่างที่ Codex ของผู้เล่นรู้อยู่แล้วซึ่งตัวหลอกไม่มี
- ผู้ต้องสงสัยตัวหลอกพกของชิ้นเดียวกับที่พยานเห็น แต่มีข้อแก้ตัวที่ยืนยันได้ และมีอาการของสิ่งลี้ลับตัวหลอก
- `validateCase` ตรวจทุกคดีก่อนปล่อยออกมา และเทสต์รันครั้งละ 2,000 seed

## จบรัน

- เฉลยเป็น 4 ชั้น: ผลลัพธ์ → ความจริง → สิ่งที่พลาด → เข้า Codex
- เกรด S/A (ถูกทั้งคู่), B (ถูกคน ผิดประเภท), C (ถูกประเภท ผิดคน), F
- ราคาที่จ่ายอยู่ในเนื้อเรื่อง ความรู้ใน Codex ไม่หายเลย: ลายเซ็นของคนร้ายตัวจริงจะเข้า Codex ทุกครั้งแม้จะตอบผิด

## ข้ามรัน

- Codex (localStorage ผ่าน `CodexStorage` เปลี่ยนไปใช้ Steam Cloud ได้ทีหลัง)
- ปลดล็อก: ผู้มาจากห้วงลึก (หลังจบคดีแรก), เข็มทิศเงิน (หลังไขคดีสำเร็จครั้งแรก)
- มหากาพย์: ชิ้นส่วนลายเซ็นฆาตกรต่อเนื่องบนโต๊ะเหยื่อ 3 ชิ้น → คดีปิดฉาก (ยังไม่ทำใน demo)

## สิ่งที่ demo เลือกไปก่อน (ยังเปลี่ยนได้)

1. **มุมมอง:** ผสม ใช้ point-and-click สำหรับที่เกิดเหตุและแผนที่ ส่วนสืบพยานกับชี้ตัวใช้แฟ้มคดี/กระดาน
2. **พลาดในมหากาพย์:** ไปต่อได้ แต่ฆาตกรได้เปรียบ (`epic.killerAdvantage` นับไว้แล้ว ยังไม่มีผล)
3. **ประเภทสิ่งลี้ลับ:** ผสม มีกอธิค 3 ชนิด (มนุษย์หมาป่า แวมไพร์ กูล) + outer 1 ชนิด
